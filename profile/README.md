# K-NEW AREA

**AI 时代下的高效开源社区 · 开源价值最大化**

聚焦具身智能，连接贡献者与使用者，让代码、模型、数据集，以及实验过程中产生的中间数据获得更多复用机会。后续将逐步扩充硬件与教程。

## 从这里开始

### [进入公共信息中心 →](https://github.com/K-NEW-AREA/community)

| 你想做什么 | 入口 |
| --- | --- |
| 找代码、模型、数据集、实验数据 | [资源目录](https://github.com/K-NEW-AREA/community#资源目录) |
| 贡献自己的资源或推荐已有资源 | [资源投稿](https://github.com/K-NEW-AREA/community/issues/new/choose) · [投稿指南](https://github.com/K-NEW-AREA/community/blob/main/CONTRIBUTING.md) |
| 找任务、找伙伴、参与共创 | [共创任务与投稿进展](https://github.com/K-NEW-AREA/community/issues) |
| 提问、交流、分享复用经验 | [Discussions 交流区](https://github.com/K-NEW-AREA/community/discussions) |

## 我们特别欢迎实验数据

未被论文采用、没有达到原目标、失败或中止实验留下的资料，也可能帮助其他人。欢迎分享可公开的日志、轨迹、评测记录和中间产物，并说明实验条件、实际观察、局限与许可；结果是否正向不是收录前提。
