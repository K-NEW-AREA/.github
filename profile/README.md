# K-NEW AREA

聚焦具身智能的开源社区，欢迎共同贡献模型、框架、数据集和学习资料。

## 从这里开始

- [数据集目录与下载说明](https://github.com/K-NEW-AREA/datasets)：查看已收录的数据集与使用入口。
- [Catch123 数据集](https://modelscope.cn/datasets/AlicePotter/Catch123)：数据文件托管在 ModelScope；GitHub 上有[对应说明](https://github.com/K-NEW-AREA/datasets/blob/main/datasets/Catch123.md)。

## 参与社区

欢迎在[数据集仓库的 Issues](https://github.com/K-NEW-AREA/datasets/issues)提出问题、补充数据说明或建议使用示例。提交 Pull Request 时，请附上来源链接和可复现的步骤。模型、框架及其他资料将随具体项目逐步整理和发布。

我们希望每一项公开内容都有明确的来源、许可和使用方法。
